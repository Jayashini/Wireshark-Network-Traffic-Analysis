<h4> Main objective </h4>
To gain practical knowledge of network traffic analysis and basic network security monitoring using Wireshark.
<h4> Objective </h4>
Learn how to capture network packets using Wireshark.
Understand the structure and information contained in network packets.
Analyze common network protocols.
Understand the TCP three-way handshake.
Analyze DNS queries and responses.
Observe ARP communication.
Analyze ICMP traffic generated using ping.
Understand the difference between HTTP and HTTPS traffic.
Identify IP addresses, ports, protocols, and TCP flags from captured packets.
Investigate patterns that may indicate suspicious network activity.
